# Siemens Energy Industrial Load Intelligence Platform

A complete, self-contained web application analyzing 321 electricity consumer profiles over 156 weeks using PCA and K-Means segmentation.

## How to Open on Any Laptop (Mac, Windows, Linux)

### Option 1: Just Double-Click (Zero Setup Needed)
1. Extract or copy the folder to the new laptop.
2. Double-click `index.html` to open it in Chrome, Edge, Safari, or Firefox.
3. Everything is bundled locally—no internet connection, Python, or server required!

### Option 2: Run a Local Web Server (Optional)
If you prefer running via localhost:
```bash
# In this directory:
python3 -m http.server 8080
```
Then open: `http://localhost:8080` in your web browser.
